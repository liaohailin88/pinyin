# 廖八一的小芽学堂

适合家长陪伴一年级孩子使用的手机学习网页。固定使用“廖八一”，学习内容逐字注音，可关闭拼音练习认字。

## 功能

- 2024修订统编人教版一年级上下册，按课列出识字表和写字表。上册新增280字、会写100字；下册新增410字、会写200字，另展示3个上册已学多音复习字。全学年690个不同字形。
- 所有目标字都有组词和例句，包含廖八一的名字，如“好 → 好人 → 廖八一是一个好人”，可分别点读。
- 上下册、会认/会写、课次筛选；汉字、词语或拼音搜索；每页18字。
- 8篇教材古诗、1篇拓展古诗、17篇原创短文，支持全篇和分句点读。
- 家长可在“朗读时光 → 家长添加”录入课文（最多200篇，每篇3000字）。正文中的 @ 代表孩子名字。自动加拼音，只保存于当前设备。
- 拼音卡片，20/100/200以内加减法，九九乘法表与练习，成长星奖励。

教材版次和来源见 [SOURCES.md](SOURCES.md)。现代教材课文没有整套内置，原创短文单独标记。自动注音应结合教材核对；拼音单音的近似语音需要家长示范。

## 教材目录与正文

“朗读时光”默认打开课本目录，包含上下册全部识字课、拼音课及阅读主课，另补充已核对的上册拼音儿歌与部分园地篇目。附属阅读目录仍在核对，不能把目录当成全文。《洗手歌》对应上册拼音第10课、第46页，《欢迎台湾小朋友》对应第11课、第48页；家长确认第一句为“一只船，扬起帆”，与2024修订版相符。现代课文条目标明“待家长提供正文”；点击后可预填标题，在本机录入、注音和点读。

页面固定使用廖八一；家庭例句设定为哥哥和两个弟弟。iPad横竖屏按视口宽度适配，也支持分屏缩小到手机布局。

## 本机与手机打开

在本目录运行：

```powershell
python -m http.server 8080 --bind 0.0.0.0
```

电脑打开 http://localhost:8080 。手机与电脑接入同一局域网后，打开 `http://电脑IPv4地址:8080`；运行 `ipconfig` 查看地址。电脑需保持运行，防火墙需允许专用网络访问。此服务器用于可信局域网，不要直接暴露到公网。

运行网页不需要npm、账号或构建，拼音代码已包含于vendor/。设备需要支持中文SpeechSynthesis，不同设备声音有所不同。

## 检查和打包

开发检查使用Node.js 22及以上：

```powershell
npm ci
npm test
npm run build
```

检查覆盖4万次数学出题、字表数量及例句完整性、固定姓名、注音覆盖、搜索筛选、朗读文本、课文添加及保存。dist/只包含运行所需的网页和本地拼音资源，不包含开发依赖、测试或缓存。

## 发布到GitHub

目标仓库：https://github.com/liaohailin88/pinyin

将源码提交到仓库main分支。仓库Settings → Pages → Build and deployment → Source选择GitHub Actions。本项目.github/workflows/pages.yml自动检查、打包和部署dist/。

成功后，默认访问地址为 https://liaohailin88.github.io/pinyin/ 。只有Actions部署成功才表示已上线；本地完成不等于已经推送。

也可以解压提供的源码压缩包，将其中的文件以及.github文件夹上传到仓库，不要只上传压缩包。已有仓库先合并远端内容，不要强制覆盖历史。

## 数据保存

拼音开关、成长星、已学字和家长添加的课文保存在当前浏览器。换设备或清理浏览器数据不会保留进度。没有录音或自动发音评分。

## 老师重点：上册第57页

根据家长提供的教材照片，拼音乐园默认展示“老师重点”：ie/ei与iu/ui对比词，9个秋游拼读词语及选择说话练习，23个声母、24个韵母、16个整体认读音节，廖八一名字的三拼/两拼/整体认读示例，以及6道辨认练习。词语标调按照片录入，单音点读仍仅为设备近似提示，需要家长示范。
